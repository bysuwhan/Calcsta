# Calcsta

[calcsta.pages.dev](https://calcsta.pages.dev)

2D CAD스타일로 빠르게 스케치하고 간단한 정역학 계산이 가능한 프로그램입니다.

## 개요

- [Stabileo](https://github.com/lambdaclass/stabileo)를 기반으로 한 비공식 수정판입니다. 고급 기능을 원하시면 Stabileo 를 사용하시기 바랍니다.
- 2D 트러스 구조 해석을 위한 기초적인 기능.
- CAD 스타일로 스케치하고 구속조건을 줄 수 있습니다.

## Stabileo 와의 차이점

- 스케치 블록기능 추가.
- CAD 스타일로 빠르게 스케치하고 변형할 수 있도록 함.
- 상세한 해석 및 경계조건 기능들 제거.

## 시작하기

**바로 사용하기:** 최신 브라우저에서 [calcsta.pages.dev](https://calcsta.pages.dev)을 여세요.

**로컬 실행:**

```bash
git clone https://github.com/bysuwhan/Calcsta.git
cd Calcsta/web
npm install
npm run dev       # http://localhost:4000
```
